# AGENTS.md

Instructions for Codex, Antigravity and other coding agents in this repo.

**The canonical instructions are in `./CLAUDE.md`. Read it first and follow it**, except where it names a Claude-only tool. If `./CLAUDE.local.md` exists, read it too: it holds Mac-only rules. Don't copy rules into this file.

Then read the top handoff of `RALPH_TASK.md`, and `docs/GUARDRAILS.md` before touching movement, construction, mining, inventory persistence or Souls.

If you run as an offloaded job, stay in your job's worktree, make no commits, and report what you changed and what you could not verify. Never deploy a JAR, touch a game instance or run the game.
